Analysis deliverables are a hand-written markdown report (`*_report.md`) whose images live in a
`fig/` folder next to it, produced by a reproducible script (e.g. `EDA/eda.py`,
`mileage/pilot.py`) that also prints the quoted numbers. No notebooks.

**Why:** on 2026-11-20 the user stopped a notebook-based EDA mid-way and asked for
`eda_report.md` + `./fig` instead; the same format was then used for the mileage pilot.

**How to apply:** for any new analysis/experiment write `script.py` -> `fig/NN_name.png` + stdout
numbers, then the report in Russian referencing `fig/...`; re-check every number in the report
against the script output before handing it over. See [[user-profile]].
